# ms-swift 源码解析

基于 [ms-swift](https://github.com/modelscope/ms-swift) 框架的深度技术剖析，系统性解析大模型微调的核心架构、损失函数、RLHF 算法与超参数体系。

## 在线阅读

https://your-username.github.io/ms-swift-book/

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```

## 本书特色

- **35 章完整内容**：从基础概念到高级特性，覆盖 ms-swift 的所有核心模块
- **损失函数深度剖析**：7 种损失函数的数学原理、实现细节、适用场景对比
- **RLHF 算法全覆盖**：DPO 的 14 种变体、CPO/SimPO、ORPO、KTO、PPO、GRPO、GKD
- **超参数完全指南**：100+ 个超参数的作用、默认值、调优建议
- **代码驱动**：每个概念都配有真实源码片段和详细注释
