# 第 26 章 Reward Model 训练

## 26.1 奖励模型的作用

奖励模型（Reward Model, RM）是 RLHF 流程中的关键组件，用于将人类偏好建模为标量分数。

**用途：**
- PPO 训练需要奖励模型
- 评估模型输出质量
- 作为 GRPO 的替代方案（规则奖励 vs 学习奖励）

## 26.2 奖励模型训练原理

**核心公式：**

$$\mathcal{L}_{RM} = -\log\sigma(r(x, y_w) - r(x, y_l))$$

其中：
- $r(x, y)$：奖励模型对 $(x, y)$ 的打分
- $y_w$：chosen response
- $y_l$：rejected response

**目标：** chosen 的分数应该高于 rejected 的分数。

## 26.3 实现细节

```python
# swift/rlhf_trainers/reward_trainer.py

class RewardTrainer(RLHFTrainerMixin, SwiftMixin, HFRewardTrainer):
    
    def compute_loss(self, model, inputs, return_outputs=False, num_items_in_batch=None):
        # 提取 margin（可选）
        margin = inputs.pop('margin', None)
        
        # 前向传播
        rewards = model(**inputs).logits
        rewards_chosen, rewards_rejected = torch.split(rewards, batch_size, dim=0)
        
        # 计算损失
        if margin is not None:
            loss = -nn.functional.logsigmoid(rewards_chosen - rewards_rejected - margin).mean()
        else:
            loss = -nn.functional.logsigmoid(rewards_chosen - rewards_rejected).mean()
        
        # 可选：中心奖励损失
        if self.args.center_rewards_coefficient is not None:
            center_rewards_loss = self.args.center_rewards_coefficient * torch.mean(
                (rewards_chosen + rewards_rejected)**2)
            loss += center_rewards_loss
        
        return loss
```

## 26.4 关键超参数

### center_rewards_coefficient

```python
center_rewards_coefficient: Optional[float] = None
```

**作用：** 鼓励奖励模型输出均值为 0 的奖励。

$$\mathcal{L}_{center} = \text{coeff} \cdot \mathbb{E}[(r_w + r_l)^2]$$

**推荐值：** 0.01

### task_type

```python
# RM 训练自动设置
if self.rlhf_type == 'rm':
    self.task_type = 'seq_cls'
    self.num_labels = 1
```

**说明：** 奖励模型使用序列分类任务，输出单个标量。

## 26.7 评估指标

奖励模型训练时自动记录以下指标：

```python
self.custom_metrics[mode]['rewards/chosen'].update(rewards_chosen.mean())
self.custom_metrics[mode]['rewards/rejected'].update(rewards_rejected.mean())
self.custom_metrics[mode]['rewards/accuracies'].update((rewards_chosen > rewards_rejected).float().mean())
self.custom_metrics[mode]['rewards/margins'].update((rewards_chosen - rewards_rejected).mean())
```

**指标说明：**
- `rewards/chosen`：chosen 的平均奖励
- `rewards/rejected`：rejected 的平均奖励
- `rewards/accuracies`：chosen > rejected 的比例（越高越好）
- `rewards/margins`：奖励差距（chosen - rejected）

## 26.10 奖励模型 vs 规则奖励

| 维度 | 奖励模型 | 规则奖励（GRPO） |
|------|---------|----------------|
| 训练数据 | 偏好数据 | 无需训练 |
| 泛化能力 | 好 | 差 |
| 计算成本 | 高（需要前向传播） | 低（规则匹配） |
| 可解释性 | 差 | 好 |
| 适用场景 | PPO | GRPO |

## 小结

- **要点 1**：奖励模型将人类偏好建模为标量分数
- **要点 2**：使用 Bradley-Terry 模型，chosen 分数应高于 rejected
- **要点 3**：center_rewards_coefficient 鼓励奖励均值为 0
- **要点 4**：训练好的奖励模型可用于 PPO 训练
